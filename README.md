# Crypto AI Central - Full Stack Crypto Directory

## 🚨 IMPORTANT: Content Not Showing?

**The GitHub repository contains CODE, not DATA.** Your database is empty.

### Quick Fix - Run the Population Script:

```bash
npm install
node populate-sample-data.js
```

This will populate your database with:
- **25+ Directory Listings** across all 14 categories
- **5 Blog Posts** with full content
- **6 Rewards** for the points system

Then your site will show all content immediately!

---

## Running the App

```bash
npm install
npm run dev
```

## Building for Production

```bash
npm run build
```

The production build will be in the `dist/` folder - upload this to your web host.
